# Data Availability

The original tracking data used in the article were obtained from Amisco Pro and cannot be shared publicly because of data access restrictions.

This folder contains only a small synthetic example file, `example_data.csv`, which shows the expected data structure for running or adapting the analysis code.

Required variables include:

- `DPGZ`
- `DPPBND`
- `Defenders_Num`
- `PL`
- `PN`
- `DLAODGL`
- `Outcome`
- `Running_score`

The example file is not the original study dataset and cannot reproduce the published numerical results.
